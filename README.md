# Global Observatory

A website that keeps track of major world events, long-term threats to humanity, and the worst disasters in history.

**[Open the site](https://guillearria.github.io/global-observatory/)**

## How it works

- An AI (Claude, made by Anthropic) does the research and the writing.
- The AI does not decide what counts as a confirmed fact. A separate program makes that call, and it applies the same fixed rules every time.
- Every number on the site links to the source it came from.
